Cryptography is a data transformation technique used to protect information from unauthorized access, theft, or compromise.
### How does encryption work?
Encryption works by altering data so that only someone who possesses a specific piece of knowledge — know as the key — can interpret the data. To decrypt the message, an algorithm-generated key is used to transform the encrypted data back into its original form.
### Cryptography types
**Symmetric encryption** uses a single key to encryption and decryption. The main disadvantage is that if someone obtains this key, they can decrypt all messages exchanged between the parties.

**Asymmetric encryption**, also know as public-key cryptography, uses two separate keys: one public key and one private key.  Anyone with the public key  can encrypt a message, but only the private key can decrypt it.
